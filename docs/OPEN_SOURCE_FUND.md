## Project fit

BRIDGE² is an MIT-licensed interoperability project that compiles one auditable capability definition into MCP plus provider-specific integration artifacts for OpenAI/Codex, Claude, Gemini, DeepSeek, Meta/Llama and browser-agent surfaces.

The funding case is maintenance depth: provider compatibility testing, security review, adapter upkeep, issue triage, release automation, documentation and reproducible verification.
